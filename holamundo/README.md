# Actividad 2 — El Taller del Programador (Hola Mundo)

Configuración del entorno de desarrollo (IDE + compilador MinGW/GCC) y primer
programa de consola en C++.

## Compilar y ejecutar

Desde la raíz de `holamundo/`, en la terminal integrada de VS Code (Ctrl + Ñ):

```powershell
g++ src/main.cpp -o src/holamundo.exe
.\src\holamundo.exe
```

## Regla obligatoria

Modificar la salida de pantalla en `src/main.cpp` agregando tu **nombre y
apellido reales** antes de compilar y entregar.
